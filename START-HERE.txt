  VIBES 3D STUDIO — START HERE
══════════════════════════════════════════════════════════════════

  1. Unzip this folder somewhere (Desktop is fine).
  2. Double-click:   START-WINDOWS.bat

  A black window opens, and your browser opens the site
  automatically at:  http://localhost:8080

  Leave the black window open while you're using the site.
  Closing it stops the server.

  That's everything. There is no step 3.


──────────────────────────────────────────────────────────────────
  NOTHING TO INSTALL, NOTHING TO DOWNLOAD
──────────────────────────────────────────────────────────────────

  This folder carries everything it needs:

    Node.js       — no need to install it
    OrcaSlicer    — the slicing engine, bundled in vendor/
    P2S profiles  — the printer settings, already set up

  No internet connection is required. No accounts, no settings,
  no first-run setup. Copy the folder to another computer and it
  still works.

  Every run starts immediately, including the first.


──────────────────────────────────────────────────────────────────
  WHAT WORKS
──────────────────────────────────────────────────────────────────

  Everything: the website, uploading models, the 3D viewer,
  resizing and rotating, and "Get exact price" — which runs a
  real slice on a real Bambu Lab P2S profile.

  The printer settings are already here — the standard P2S
  profile with a 0.4mm nozzle, 0.20mm layers, and Bambu PLA
  Basic or ASA. Nothing to pick or configure.


──────────────────────────────────────────────────────────────────
  WHERE THE PRICES COME FROM
──────────────────────────────────────────────────────────────────

  The engine is OrcaSlicer, but the settings are Bambu's.

  The profiles in server/profiles/ are built from Bambu Studio's
  own presets for the P2S — the same layer heights, speeds,
  temperatures, flow rates and filament densities the shop
  prints with. OrcaSlicer is the program that reads them.

  Why not Bambu Studio itself? It ships only as a GUI installer,
  so it cannot be carried inside a folder — which is why the
  older version of this app needed you to install Bambu Studio
  first, and said "The slicing engine isn't installed on the
  server yet" when you hadn't. OrcaSlicer is a fork of Bambu
  Studio with the same command line, and it publishes a portable
  build, so it can travel with the app.


──────────────────────────────────────────────────────────────────
  IF DOUBLE-CLICKING DOESN'T WORK
──────────────────────────────────────────────────────────────────

  A blue "Windows protected your PC" box appears:
      Click "More info" → "Run anyway"

  "This copy is incomplete":
      The zip was only partly unpacked. Unzip the whole folder
      again, and run the launcher from the unzipped copy — not
      from inside the .zip preview window.

  Port 8080 already in use:
      Something else is on that port. Open a terminal here and
      run:   vendor\node\node.exe start.js
      after setting PORT, e.g.  set PORT=8081
